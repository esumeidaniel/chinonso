# Daniel Chinonso Portfolio

A modern React + Vite developer portfolio website.

## How to run

1. Open the folder in VS Code.
2. Open terminal inside the project folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost link shown in the terminal.
